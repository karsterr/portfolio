# Profil görseli

`efe-can-kara.jpeg`, kullanıcının sağladığı özgün fotoğraftır; kökten taşınırken SHA-256 eşitliği doğrulandı. Hakkımda alanında Astro Image üzerinden, sabit en/boy ve 240/400 px WebP seçenekleriyle kullanılır.

CV kaynaklarının özgün DOCX dosyaları `design/references/cv/` altında, Git ve Docker dışında saklanır. Dosyalar indirme bağlantısı veya public kaynak olarak sunulmaz. Profil ve deneyim metinleri `.local/content/settings.json` ve `.local/content/experience/` içindedir; admin panelinden düzenlenebilir.
