# Tasarım referansları

`references/` yalnızca yerel inceleme içindir; Git ve Docker bağlamından dışlanır. Kullanıcının `referans.png` dosyası bu dizine taşındı. Bu dosya hiçbir sayfa, logo, favicon veya build girdisinde kullanılmaz.

`references/cv/` özgün Türkçe ve İngilizce CV dosyalarını saklar. Bunlar biyografi/deneyim metinlerinin kaynağıdır; dosyaların kendisi sitede sunulmaz ve yerel CMS içerik ağacına dahil edilmez.

Marka kaynakları ve siteye hazırlanan SVG'ler `src/assets/brand/` altındadır. Palet: Charcoal, Japanese Indigo, Steel Teal, Mid Grey, Foggy ve Star Dust. Ana yüzeyler nötr kalır; mavi/teal yalnızca vurgu olarak kullanılır.
